# Proposta Comercial — Rafael Nano Pigmentação Capilar

Apresentação comercial interativa de alto impacto desenvolvida pela **Ápice Digital** para o especialista **Rafael Nano Pigmentação Capilar**.

## 🚀 O Projeto

Esta aplicação é uma apresentação interativa (pitch deck) desenvolvida em React + Vite, focada em apresentar as possibilidades de evolução digital e ecossistema de vendas do especialista:
1. **Landing Page de Vendas (Curso/Mentoria)**
2. **Site Institucional High-Ticket (Autoridade & Procedimentos)**
3. **Sistema Inteligente de Pedidos de Orçamento via WhatsApp (Triagem Norwood)**

## 🎨 Design & Tecnologia

- **React + Vite**: Compilação ultrarrápida e renderização fluida.
- **Navegação Síncrona & Crash-Proof**: Sistema de transição nativo do React blindado contra travamentos, garantindo fluidez perfeita entre os 9 slides.
- **Premium Glassmorphism**: Interface focada em tons azuis/escuros (`#070D14`), com orbes em degradê fluido de alta resolução.
- **Totalmente Responsivo**: Adaptação nativa e inteligente da escala (Scale-to-fit) para Desktop (Widescreen) e Mobile (Portrait).

## 🛠️ Como executar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/limaazpsd/proposta-comercial-rafael.git
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Execute o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

## 📦 Build para Produção

Para gerar a versão estática e otimizada de produção:
```bash
npm run build
```
Os arquivos minificados estarão disponíveis na pasta `dist/` (configurado para deploy instantâneo na Vercel ou Netlify).
